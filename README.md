
# Factor Risk Model

A Python project for explaining portfolio returns using
market, momentum, value, and size factors.
# Planned features

- Historical stock return analysis
- Factor construction
- Regression based factor exposure estimation
- Principal Component Analysis (PCA)
- Historical and hypothetical stress testing
- Interactive portfolio risk dashboard

# Status

Initial development.

# Technology used

Python, Pandas, NumPy, statsmodels, scikit-learn,
Matplotlib, Plotly, and Streamlit.
